# CodeAlpha Data Visualization Project

## Project Overview
This project focuses on analyzing and visualizing sales data using Python. It transforms raw sales data into meaningful charts to identify trends and business insights.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## Dataset
The project uses `sales_data.csv`, which contains sales information such as:
- Order ID
- Date
- Product
- Category
- Quantity
- Unit Price
- Region

## Visualizations Created

### 1. Product-wise Sales Analysis
A horizontal bar chart comparing total sales generated by each product.

**Insight:** Laptop generated the highest sales of ₹3,30,000.

### 2. Region-wise Sales Distribution
A pie chart showing the percentage contribution of each region.

**Insight:** South region generated the highest sales of ₹2,34,000.

### 3. Monthly Sales Trend
A line chart showing changes in sales from January to May 2026.

**Insight:** May recorded the highest monthly sales of ₹1,45,900.

### 4. Category-wise Sales Comparison
A bar chart comparing sales across product categories.

**Insight:** Electronics generated ₹5,14,000, while Accessories generated ₹60,500.

## How to Run the Project

1. Install the required libraries:

```bash
pip install pandas matplotlib seaborn
```

2. Run the Python script:

```bash
python data_visualization.py
```

3. The charts will be saved automatically in the project folder.
