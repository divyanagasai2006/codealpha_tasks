# CodeAlpha Data Analytics Internship Projects

This repository contains three projects completed as part of the CodeAlpha Data Analytics Internship.

## Task 2: Exploratory Data Analysis (EDA)
- Analyzed sales data using Python and Pandas.
- Identified product-wise, region-wise, and monthly sales trends.
- Checked missing values, duplicates, and unusual values.
- Generated visualizations using Matplotlib and Seaborn.

## Task 3: Data Visualization
- Created charts to understand sales data.
- Visualized product-wise, region-wise, monthly, and category-wise sales.
- Used Python, Pandas, Matplotlib, and Seaborn.

## Task 4: Sentiment Analysis
- Analyzed customer reviews using Natural Language Processing.
- Used NLTK VADER Sentiment Analyzer.
- Classified reviews as Positive, Negative, or Neutral.
- Generated sentiment distribution charts.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- NLTK
- VADER Sentiment Analysis
